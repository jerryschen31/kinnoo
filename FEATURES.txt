    description: |
      Define the kinnoo.yaml manifest schema and implement a validator that parses
      and validates manifest files against it. The validator returns clear, actionable
      error messages and is usable as a library function for other commands (pack, run, etc.).

      Schema definition:
      | Field              | Required | Type         | Constraints                                      |
      |--------------------|----------|--------------|--------------------------------------------------|
      | name               | yes      | string       | non-empty, valid package name (alphanumeric, -)  |
      | version            | yes      | string       | valid semver (e.g., "0.1.0", "1.2.3")            |
      | entrypoint         | yes      | string       | non-empty file path                              |
      | runtime.language   | yes      | string       | e.g., "python"                                   |
      | runtime.version    | yes      | string       | version constraint (e.g., ">=3.10")              |
      | runtime.type       | yes      | string       | e.g., "one-shot"                                 |
      | dependencies       | yes      | list[string] | can be empty list                                |
      | inputs.type        | yes      | string       | e.g., "text"                                     |
      | outputs.type       | yes      | string       | e.g., "text"                                     |
      | framework          | no       | string       | optional, e.g., "langchain"                      |
    tasks: [task0, task1, task2, task3]
